# Fillcard

Lash maps, client records and refill cards for independent lash artists. A free web app that installs to the phone's home screen. Client data stays on the artist's device.

- Save each client's lash map in seconds; next fill starts from her last map
- Send her a refill card and a lash passport link (map, aftercare, refill countdown, booking button, calendar reminder)
- See who's overdue and remind them in one tap
- Signed consent forms, style preview on her eye photo, eye-shape guide

It's a static site with no build step: `index.html`, `sw.js`, `manifest.webmanifest`, `icon.svg`.
